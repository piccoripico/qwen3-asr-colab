# Qwen3-ASR Colab

Notebooky Google Colab pro přepis audio a video souborů pomocí Qwen3-ASR.

## Funkce

- **Zdarma:** Qwen3-ASR s bezplatným GPU Google Colab.
- **Časové značky a titulky:** pro jazyky podporované Qwen3-ForcedAligner jsou dostupné zarovnané časové značky a SRT.
- **Žádný pevný limit velikosti souboru na straně notebooku:** lze zpracovat dlouhé soubory.
- **Dávkové zpracování:** více souborů v jednom běhu.
- **Google Drive:** přímé nahrání nebo čtení z Google Drive.
- **Plně online:** stažení modelu a přepis probíhají v Google Colab.
- **Více formátů:** JSON, TXT, CSV, Markdown, Excel a SRT.
- **Kontext:** `CONTEXT_INFO` může obsahovat jména, organizace a technické termíny.

## Struktura repozitáře

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Šablona notebooku je společným zdrojem kódu. Locale soubory poskytují jazykově specifický text pro rozhraní Colab, například `# @title`, `# @markdown`, komentáře a vybrané zprávy. Každý locale obsahuje úplnou sadu placeholderů z kurátorovaného japonského notebooku.

Vygenerované notebooky jsou commitovány, aby odkazy Colab zůstaly stabilní.

## Sestavení

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Aktualizace překladů

`translate_full_locales.py` je údržbový nástroj, který aktualizuje ostatní locale z anglického locale a chrání tokeny kódu, identifikátory modelů a nastavení Colab. Před vydáním překlady zkontrolujte.

## Kontroly

```bash
python scripts/check_notebooks.py
```

CI znovu vytváří README/notebooky a kontroluje rozdíly, JSON notebooků, syntaxi Pythonu, nevyřešené placeholdery, uložené výstupy, zjevná tajemství a konzistenci všech 30 jazykových artefaktů.

## Co může CI testovat

Repozitář může testovat notebook jako distribuovatelný artefakt:

- deterministické generování ze šablony a locale
- platnost JSON notebooku
- prázdné výstupy běhu
- syntaxe Pythonu v kódových buňkách
- žádné nevyřešené placeholdery
- žádná zjevná náhodná tajemství
- commitované README/notebooky odpovídají zdrojům

Úplná cesta přepisu vyžaduje API specifická pro Colab, stahování modelů, dostupnost GPU a média uživatele. End-to-end GPU validace proto zůstává ruční UAT. Japonská cesta byla ověřena v Google Colab na skutečném dlouhém audiu.
