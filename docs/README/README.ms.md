# Qwen3-ASR Colab

Notebook Google Colab untuk mentranskripsikan fail audio dan video dengan Qwen3-ASR.

## Ciri-ciri

- **Percuma:** menggunakan [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) dengan GPU percuma Google Colab.
- **Cap masa dan sari kata:** untuk bahasa yang disokong Qwen3-ForcedAligner, `Qwen3-ForcedAligner-0.6B` menyediakan cap masa sejajar dan menghasilkan SRT.
- **Tiada had saiz fail tetap di pihak notebook:** fail panjang boleh diproses.
- **Pemprosesan kelompok:** beberapa fail dalam satu larian.
- **Google Drive:** muat naik terus atau baca daripada Google Drive.
- **Sepenuhnya dalam talian:** muat turun model dan transkripsi berjalan di Google Colab.
- **Pelbagai format:** JSON, TXT, CSV, Markdown, Excel dan SRT.
- **Konteks:** `CONTEXT_INFO` boleh menyediakan nama, organisasi dan istilah teknikal.

## Struktur Repositori

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Notebook template ialah sumber kod bersama. Fail locale menyediakan teks khusus bahasa untuk paparan Colab seperti `# @title`, `# @markdown`, komen dan beberapa mesej pengguna. Setiap locale mempunyai set placeholder lengkap yang sama dengan notebook Jepun yang dikurasi.

Notebook yang dijana dicommit supaya pautan Colab kekal stabil.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Kemas Kini Terjemahan

`translate_full_locales.py` ialah alat penyelenggaraan untuk mengemas kini locale lain daripada locale Inggeris sambil melindungi token kod, pengecam model dan tetapan Colab. Semak terjemahan sebelum keluaran rasmi.

## Semakan

```bash
python scripts/check_notebooks.py
```

CI menjana semula README/notebook dan memeriksa perbezaan jana, Notebook JSON, sintaks Python, placeholder belum selesai, output sel tersimpan, secret yang jelas dan konsistensi artefak 30 bahasa.

## Perkara yang Boleh Diuji CI

Repositori ini boleh menguji notebook sebagai artefak boleh edar:

- penjanaan deterministik daripada template dan locale
- kesahan Notebook JSON
- output pelaksanaan kosong
- sintaks Python dalam sel kod
- tiada placeholder belum selesai
- secret tidak sengaja yang jelas
- README/notebook yang dicommit sepadan dengan sumber

Laluan transkripsi penuh memerlukan API khusus Colab, muat turun model, ketersediaan GPU dan media pengguna. Oleh itu pengesahan GPU end-to-end kekal sebagai UAT manual. Laluan Jepun telah disahkan di Google Colab dengan audio panjang sebenar.
