# Qwen3-ASR Colab

Google Colab-notebooks til transskription af lyd- og videofiler med Qwen3-ASR.

## Funktioner

- **Gratis:** bruger [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) med Google Colabs gratis GPU.
- **Tidsstempler og undertekster:** for Qwen3-ForcedAligner-understøttede sprog leverer `Qwen3-ForcedAligner-0.6B` justerede tidsstempler og SRT.
- **Ingen fast filstørrelsesgrænse på notebook-siden:** lange filer kan behandles.
- **Batchbehandling:** flere filer i én kørsel.
- **Google Drive:** direkte upload eller læsning fra Google Drive.
- **Fuldstændig online:** modeldownload og transskription på Google Colab.
- **Flere formater:** JSON, TXT, CSV, Markdown, Excel og SRT.
- **Kontekst:** `CONTEXT_INFO` kan indeholde navne, organisationer og tekniske termer.

## Repositorystruktur

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Template-notebooken er den fælles kodekilde. Locale-filer indeholder sprogspecifik tekst til Colab som `# @title`, `# @markdown`, kommentarer og udvalgte brugermeddelelser. Hver locale har hele placeholder-sættet fra den kuraterede japanske notebook.

Genererede notebooks committes for at holde Colab-links stabile.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Opdater oversættelser

`translate_full_locales.py` er et vedligeholdelsesværktøj, der opdaterer andre locales fra engelsk, mens code tokens, model-ID’er og Colab-indstillinger beskyttes. Gennemgå oversættelser før en formel release.

## Kontroller

```bash
python scripts/check_notebooks.py
```

CI genopbygger README/notebooks og kontrollerer genereringsforskelle, Notebook JSON, Python-syntaks, uløste placeholders, gemt celleoutput, tydelige secrets og konsistens for alle 30 sprog.

## Hvad CI kan teste

Dette repository kan teste notebooken som distribuerbart artefakt:

- deterministisk generering fra template og locale
- gyldig Notebook JSON
- tomme eksekveringsoutputs
- Python-syntaks i codeceller
- ingen uløste placeholders
- ingen tydelige utilsigtede secrets
- committede README/notebooks matcher deres kilder

Den fulde transskriptionsvej kræver Colab-specifikke API’er, modeldownloads, GPU-tilgængelighed og brugerens mediefiler. GPU end-to-end-validering er derfor fortsat manuel UAT. Den japanske vej er valideret i Google Colab med ægte lang lyd.
