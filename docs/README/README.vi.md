# Qwen3-ASR Colab

Notebook Google Colab để phiên âm tệp âm thanh và video bằng Qwen3-ASR.

## Tính năng

- **Miễn phí:** dùng [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) với GPU miễn phí của Google Colab.
- **Mốc thời gian và phụ đề:** với ngôn ngữ được Qwen3-ForcedAligner hỗ trợ, `Qwen3-ForcedAligner-0.6B` cung cấp mốc thời gian căn chỉnh và tạo SRT.
- **Không có giới hạn kích thước tệp cố định từ phía notebook:** có thể xử lý tệp dài.
- **Xử lý hàng loạt:** nhiều tệp trong một lần chạy.
- **Google Drive:** tải trực tiếp hoặc đọc từ Google Drive.
- **Hoàn toàn trực tuyến:** tải mô hình và phiên âm trên Google Colab.
- **Nhiều định dạng:** JSON, TXT, CSV, Markdown, Excel và SRT.
- **Ngữ cảnh:** `CONTEXT_INFO` có thể cung cấp tên, tổ chức và thuật ngữ kỹ thuật.

## Cấu trúc kho mã

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Notebook template là nguồn mã dùng chung. Các tệp locale cung cấp văn bản theo ngôn ngữ cho giao diện Colab như `# @title`, `# @markdown`, chú thích và một số thông báo người dùng. Mỗi locale có đầy đủ bộ placeholder giống notebook tiếng Nhật đã được chỉnh sửa thủ công.

Notebook đã tạo được commit để liên kết Colab luôn ổn định.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Cập nhật bản dịch

`translate_full_locales.py` là công cụ bảo trì để cập nhật các locale khác từ locale tiếng Anh trong khi bảo vệ token mã, định danh mô hình và cài đặt Colab. Hãy kiểm tra bản dịch trước khi phát hành chính thức.

## Kiểm tra

```bash
python scripts/check_notebooks.py
```

CI tạo lại README/notebook và kiểm tra khác biệt sinh ra, Notebook JSON, cú pháp Python, placeholder chưa giải quyết, output ô đã lưu, secret rõ ràng và tính nhất quán của artefact cho cả 30 ngôn ngữ.

## CI có thể kiểm tra gì

Kho mã này có thể kiểm tra notebook như một artefact phân phối:

- sinh xác định từ template và locale
- Notebook JSON hợp lệ
- output thực thi trống
- cú pháp Python trong ô mã
- không còn placeholder chưa giải quyết
- secret vô tình rõ ràng
- README/notebook đã commit khớp nguồn

Luồng phiên âm đầy đủ cần API riêng của Colab, tải mô hình, GPU sẵn có và media do người dùng cung cấp. Vì vậy kiểm thử GPU end-to-end vẫn là UAT thủ công. Luồng tiếng Nhật đã được xác minh trên Google Colab với audio dài thực tế.
