# Qwen3-ASR Colab

Notebook-uri Google Colab pentru transcrierea fișierelor audio și video cu Qwen3-ASR.

## Funcții

- **Utilizare gratuită:** Qwen3-ASR cu GPU-ul gratuit Google Colab.
- **Marcaje de timp și subtitrări:** pentru limbile acceptate de Qwen3-ForcedAligner sunt disponibile marcaje aliniate și SRT.
- **Fără limită fixă de dimensiune din partea notebook-ului:** pot fi procesate fișiere lungi.
- **Procesare în lot:** mai multe fișiere într-o singură rulare.
- **Google Drive:** încărcare directă sau citire din Google Drive.
- **Complet online:** descărcarea modelului și transcrierea rulează în Google Colab.
- **Mai multe formate:** JSON, TXT, CSV, Markdown, Excel și SRT.
- **Context:** `CONTEXT_INFO` poate furniza nume, organizații și termeni tehnici.

## Structura repository-ului

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Notebook-ul template este sursa comună de cod. Fișierele locale furnizează text specific limbii pentru elemente Colab precum `# @title`, `# @markdown`, comentarii și anumite mesaje. Fiecare locale conține setul complet de placeholder din notebook-ul japonez îngrijit.

Notebook-urile generate sunt commit-uite pentru ca linkurile Colab să rămână stabile.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Actualizare traduceri

`translate_full_locales.py` este un instrument de mentenanță care actualizează celelalte locale din locale-ul englez, păstrând code tokens, model identifiers și setările Colab. Revizuiți traducerile înainte de o lansare oficială.

## Verificări

```bash
python scripts/check_notebooks.py
```

CI reconstruiește README/notebook-urile și verifică diferențele, notebook JSON, sintaxa Python, placeholder-ele nerezolvate, output-urile salvate, secrets evidente și consistența tuturor celor 30 de artefacte lingvistice.

## Ce poate testa CI

Repository-ul poate testa notebook-ul ca artefact distribuibil:

- generare deterministă din template și locale
- validitatea notebook JSON
- output-uri de execuție goale
- sintaxă Python în code cells
- fără placeholder-e nerezolvate
- fără secrets accidentale evidente
- README/notebook-urile commit-uite corespund surselor

Calea completă de transcriere necesită API-uri specifice Colab, descărcarea modelelor, disponibilitate GPU și media furnizată de utilizator. Validarea GPU end-to-end rămâne UAT manual. Calea japoneză a fost validată în Google Colab cu audio real de lungă durată.
