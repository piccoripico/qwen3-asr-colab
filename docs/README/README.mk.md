# Qwen3-ASR Colab

Google Colab notebooks за транскрипција на аудио и видео датотеки со Qwen3-ASR.

## Можности

- **Бесплатно:** Qwen3-ASR со бесплатниот GPU на Google Colab.
- **Временски ознаки и преводи:** за јазиците поддржани од Qwen3-ForcedAligner се достапни порамнети временски ознаки и SRT.
- **Нема фиксно notebook ограничување на големина:** може да се обработуваат долги датотеки.
- **Сериска обработка:** повеќе датотеки во едно извршување.
- **Google Drive:** директно прикачување или читање од Google Drive.
- **Целосно online:** преземање модел и транскрипција на Google Colab.
- **Повеќе формати:** JSON, TXT, CSV, Markdown, Excel и SRT.
- **Контекст:** `CONTEXT_INFO` може да даде имиња, организации и технички термини.

## Структура на репозиториум

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Template notebook е заеднички извор на код. Locale датотеките даваат текст специфичен за јазик за Colab, како `# @title`, `# @markdown`, коментари и избрани пораки. Секој locale го содржи целосниот placeholder сет од уредениот јапонски notebook.

Генерираните notebooks се commit-ираат за Colab врските да останат стабилни.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Освежување преводи

`translate_full_locales.py` е алатка за одржување што ги освежува другите locale од англискиот, зачувувајќи code tokens, model identifiers и Colab settings. Прегледајте ги преводите пред официјално издание.

## Проверки

```bash
python scripts/check_notebooks.py
```

CI повторно ги создава README/notebooks и проверува разлики, notebook JSON, Python синтакса, нерешени placeholders, зачувани outputs, очигледни secrets и конзистентност на сите 30 јазични artefacts.

## Што може да тестира CI

Репозиториумот може да го тестира notebook како дистрибутивен artefact:

- детерминистичко генерирање од template и locale
- валидност на notebook JSON
- празни execution outputs
- Python синтакса во code cells
- без нерешени placeholders
- без очигледни случајни secrets
- commit-ираните README/notebooks одговараат на изворите

Целосната транскрипција бара Colab-specific APIs, преземање модели, достапност на GPU и кориснички медиуми. GPU end-to-end валидацијата останува рачен UAT. Јапонската патека е валидирана во Google Colab со реално долго аудио.
