# Qwen3-ASR Colab

نوت‌بوک‌های Google Colab برای رونویسی فایل‌های صوتی و ویدیویی با Qwen3-ASR.

## قابلیت‌ها

- **استفاده رایگان:** Qwen3-ASR همراه با GPU رایگان Google Colab.
- **مهر زمانی و زیرنویس:** برای زبان‌های پشتیبانی‌شده توسط Qwen3-ForcedAligner، مهر زمانی هم‌تراز و SRT در دسترس است.
- **بدون محدودیت ثابت اندازه فایل در نوت‌بوک:** فایل‌های طولانی قابل پردازش‌اند.
- **پردازش دسته‌ای:** چند فایل در یک اجرا.
- **Google Drive:** بارگذاری مستقیم یا خواندن از Google Drive.
- **کاملاً آنلاین:** دانلود مدل و رونویسی در Google Colab انجام می‌شود.
- **چند قالب:** JSON، TXT، CSV، Markdown، Excel و SRT.
- **زمینه:** `CONTEXT_INFO` می‌تواند نام‌ها، سازمان‌ها و اصطلاحات فنی را فراهم کند.

## ساختار مخزن

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

نوت‌بوک قالب منبع مشترک کد است. فایل‌های locale متن ویژه هر زبان را برای رابط Colab مانند `# @title`، `# @markdown`، توضیحات و برخی پیام‌ها فراهم می‌کنند. هر locale مجموعه کامل placeholderهای نوت‌بوک ژاپنی ویرایش‌شده را دارد.

نوت‌بوک‌های تولیدشده commit می‌شوند تا پیوندهای Colab پایدار بمانند.

## ساخت

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## به‌روزرسانی ترجمه‌ها

`translate_full_locales.py` ابزار نگهداری برای به‌روزرسانی localeهای دیگر از locale انگلیسی است و tokenهای کد، شناسه‌های مدل و تنظیمات Colab را حفظ می‌کند. ترجمه‌ها را پیش از انتشار رسمی بازبینی کنید.

## بررسی‌ها

```bash
python scripts/check_notebooks.py
```

CI فایل‌های README/notebook را دوباره می‌سازد و تفاوت‌ها، JSON نوت‌بوک، نحو Python، placeholderهای حل‌نشده، خروجی‌های ذخیره‌شده، secretهای آشکار و سازگاری همه ۳۰ artefact زبانی را بررسی می‌کند.

## موارد قابل آزمون توسط CI

این مخزن می‌تواند نوت‌بوک را به‌عنوان artefact توزیع‌شدنی آزمایش کند:

- تولید قطعی از قالب و فایل‌های locale
- اعتبار JSON نوت‌بوک
- خالی بودن خروجی‌های اجرا
- نحو Python در سلول‌های کد
- نبود placeholder حل‌نشده
- نبود secret تصادفی آشکار
- تطابق README/notebookهای commitشده با منابع

مسیر کامل رونویسی به APIهای ویژه Colab، دانلود مدل، دسترسی GPU و رسانه کاربر نیاز دارد. اعتبارسنجی GPU سرتاسری به‌صورت UAT دستی باقی می‌ماند. مسیر ژاپنی در Google Colab با صدای طولانی واقعی اعتبارسنجی شده است.
