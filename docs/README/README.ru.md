# Qwen3-ASR Colab

Notebooks Google Colab для транскрипции аудио- и видеофайлов с Qwen3-ASR.

## Возможности

- **Бесплатно:** [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) с бесплатной GPU-средой Google Colab.
- **Временные метки и субтитры:** для языков Qwen3-ForcedAligner `Qwen3-ForcedAligner-0.6B` выдаёт выровненные временные метки и создаёт SRT.
- **Нет фиксированного ограничения размера файла со стороны notebook:** можно обрабатывать длинные файлы.
- **Пакетная обработка:** несколько файлов за один запуск.
- **Google Drive:** прямой upload или чтение из Google Drive.
- **Полностью онлайн:** загрузка модели и транскрипция выполняются в Google Colab.
- **Несколько форматов:** JSON, TXT, CSV, Markdown, Excel и SRT.
- **Контекст:** `CONTEXT_INFO` может содержать имена, организации и технические термины.

## Структура репозитория

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Template notebook является общей исходной версией кода. Файлы locale содержат локализованный текст для Colab, включая `# @title`, `# @markdown`, комментарии и некоторые пользовательские сообщения. Каждый locale содержит полный набор placeholders из вручную отредактированного японского notebook.

Сгенерированные notebooks хранятся в репозитории, чтобы ссылки Colab оставались стабильными.

## Сборка

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Обновить переводы

`translate_full_locales.py` — служебный скрипт для обновления других locales из английского с защитой code tokens, идентификаторов моделей и настроек Colab. Перед официальным релизом переводы следует проверить.

## Проверки

```bash
python scripts/check_notebooks.py
```

CI заново генерирует README/notebooks и проверяет различия, Notebook JSON, синтаксис Python, неразрешённые placeholders, сохранённый вывод ячеек, очевидные секреты и согласованность артефактов всех 30 языков.

## Что проверяет CI

Репозиторий может проверять notebook как распространяемый артефакт:

- детерминированная генерация из template и locale
- валидность Notebook JSON
- пустой вывод выполнения
- синтаксис Python в кодовых ячейках
- отсутствие неразрешённых placeholders
- очевидные случайно добавленные секреты
- сгенерированные README/notebooks соответствуют исходникам

Полный путь транскрипции требует Colab-специфичных API, загрузки моделей, доступной GPU и пользовательских медиафайлов. Поэтому GPU end-to-end остаётся ручным UAT. Японский путь проверен в Google Colab на реальном длинном аудио.
