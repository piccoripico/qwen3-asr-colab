# Qwen3-ASR Colab

Notebooks Google Colab pour transcrire des fichiers audio et vidéo avec Qwen3-ASR.

## Fonctionnalités

- **Gratuit :** utilise [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) avec le GPU gratuit de Google Colab.
- **Horodatage et sous-titres :** pour les langues prises en charge par Qwen3-ForcedAligner, `Qwen3-ForcedAligner-0.6B` fournit des horodatages alignés et génère des sous-titres SRT.
- **Pas de limite fixe de taille de fichier côté notebook :** les fichiers audio et vidéo longs peuvent être traités.
- **Traitement par lots :** plusieurs fichiers peuvent être traités en une seule exécution.
- **Google Drive :** les fichiers peuvent être téléversés directement ou lus depuis Google Drive.
- **Entièrement en ligne :** le téléchargement du modèle et la transcription s’exécutent sur Google Colab.
- **Plusieurs formats :** JSON, TXT, CSV, Markdown, Excel et SRT sont pris en charge.
- **Contexte :** `CONTEXT_INFO` peut fournir des noms, organisations et termes techniques.

## Structure du dépôt

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Le notebook modèle est la source commune du code. Les fichiers locale fournissent les textes propres à chaque langue pour l’interface Colab, tels que `# @title`, `# @markdown`, les commentaires et certains messages utilisateur. Chaque locale contient l’ensemble complet de placeholders du notebook japonais révisé manuellement.

Les notebooks générés sont commités afin de conserver des liens Colab stables.

## Génération

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Actualiser les traductions

`translate_full_locales.py` est un outil de maintenance qui actualise les autres locales depuis la locale anglaise tout en protégeant les tokens de code, les identifiants de modèle et les paramètres Colab. Vérifiez les traductions avant une publication officielle.

## Vérifications

```bash
python scripts/check_notebooks.py
```

CI régénère les README/notebooks et vérifie les différences de génération, Notebook JSON, la syntaxe Python, les placeholders non résolus, les sorties de cellules enregistrées, les secrets évidents et la cohérence des artefacts des 30 langues.

## Ce que CI peut tester

Ce dépôt peut tester le notebook en tant qu’artefact distribuable :

- génération déterministe depuis le modèle et les fichiers locale
- validité de Notebook JSON
- sorties d’exécution vides
- syntaxe Python des cellules de code
- absence de placeholders non résolus
- secrets accidentels évidents
- README/notebooks commités conformes à leurs sources

Le parcours complet de transcription nécessite des API propres à Colab, le téléchargement des modèles, la disponibilité d’un GPU et des médias fournis par l’utilisateur. La validation GPU de bout en bout reste donc un UAT manuel. Le parcours japonais a été validé dans Google Colab avec un véritable audio long.
