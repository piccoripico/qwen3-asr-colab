# Qwen3-ASR Colab ノートブック

Qwen3-ASRをGoogle Colabで実行し、音声・動画ファイルを文字起こしするためのノートブックです。

## 特長

- **無料:** オープンソースの [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) と Google Colab の無料GPUランタイムを使用します。
- **タイムスタンプ・字幕対応:** Qwen3-ForcedAligner対応言語では `Qwen3-ForcedAligner-0.6B` を使用して時刻情報を取得し、SRT字幕ファイルを生成できます。
- **ノートブック側の固定ファイルサイズ制限なし:** 長い音声・動画ファイルも処理できます。
- **バッチ処理:** 複数の音声・動画ファイルを1回の実行で処理できます。
- **Google Drive対応:** 直接アップロードまたはGoogle Drive内のファイルを処理できます。
- **完全オンライン:** モデルのダウンロードと文字起こしはGoogle Colab上で実行されます。
- **複数の出力形式:** JSON、TXT、CSV、Markdown、Excel、SRTを出力できます。
- **コンテキスト指定:** `CONTEXT_INFO` に人名、組織名、専門用語などを指定できます。

## レポジトリ構成

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

テンプレートNotebookが共通コードの正本です。localeファイルは、`# @title`、`# @markdown`、コメント、ユーザー向けメッセージなどのColab向け文言を提供します。各localeは日本語正本と同じplaceholder一式を持ちます。

生成済みNotebookはColabリンクを安定させるためコミット対象です。

## 生成

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## 翻訳の更新

`translate_full_locales.py` は英語localeを基に他のlocaleを更新する保守用スクリプトです。コードトークン、モデル識別子、Colab設定値を保護して翻訳します。正式リリース前に翻訳文を確認してください。

## チェック

```bash
python scripts/check_notebooks.py
```

CIはREADME/Notebookを再生成し、生成差分、Notebook JSON、Python構文、未解決placeholder、保存済みcell output、秘密情報らしき文字列、30言語の生成物整合性を検査します。

## CIで確認する内容

このレポジトリでは、Notebookを配布物として次の項目を検査できます。

- templateとlocaleからの決定的生成
- Notebook JSONの妥当性
- cell output / execution_countが空であること
- コードセルのPython構文
- 未解決placeholderがないこと
- 秘密情報らしき文字列がないこと
- 生成済みREADME/Notebookがsourceと一致すること

実際の文字起こしはColab固有API、モデルダウンロード、GPU、ユーザーのメディア入力を必要とするため、GPU end-to-end UATは手動検証として扱います。日本語版の基礎経路はGoogle Colabで実際の長時間音声を使って検証済みです。
