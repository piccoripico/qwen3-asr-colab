# Qwen3-ASR Colab

Qwen3-ASR로 오디오 및 비디오 파일을 전사하는 Google Colab 노트북입니다.

## 특징

- **무료 사용:** [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR)과 Google Colab 무료 GPU 런타임을 사용합니다.
- **타임스탬프 및 자막:** Qwen3-ForcedAligner 지원 언어에서는 `Qwen3-ForcedAligner-0.6B`가 정렬된 타임스탬프와 SRT 자막을 제공합니다.
- **노트북 측 고정 파일 크기 제한 없음:** 긴 파일도 처리할 수 있습니다.
- **일괄 처리:** 여러 파일을 한 번에 처리할 수 있습니다.
- **Google Drive:** 직접 업로드하거나 Google Drive의 파일을 읽을 수 있습니다.
- **완전 온라인:** 모델 다운로드와 전사가 Google Colab에서 실행됩니다.
- **다양한 출력 형식:** JSON, TXT, CSV, Markdown, Excel, SRT를 지원합니다.
- **컨텍스트 힌트:** `CONTEXT_INFO`에 인명, 기관명, 전문 용어를 제공할 수 있습니다.

## 저장소 구조

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

템플릿 노트북이 공통 코드의 소스입니다. locale 파일은 `# @title`, `# @markdown`, 주석, 일부 사용자 메시지 등 Colab 표시 문구의 언어별 값을 제공합니다. 각 locale은 수동으로 다듬은 일본어 노트북과 동일한 전체 placeholder 집합을 가집니다.

생성된 노트북은 Colab 링크를 안정적으로 유지하기 위해 저장소에 커밋합니다.

## 생성

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## 번역 업데이트

`translate_full_locales.py`는 영어 locale을 기반으로 다른 locale을 업데이트하면서 코드 token, 모델 식별자, Colab 설정을 보호하는 유지보수 도구입니다. 정식 릴리스 전에 번역을 검토하세요.

## 검사

```bash
python scripts/check_notebooks.py
```

CI는 README/노트북을 다시 생성하고 생성 차이, Notebook JSON, Python 문법, 미해결 placeholder, 저장된 셀 출력, 명백한 secret, 30개 언어 산출물의 일관성을 검사합니다.

## CI에서 검사할 수 있는 항목

이 저장소에서는 노트북을 배포 가능한 산출물로 다음 항목을 검사할 수 있습니다:

- template과 locale에서 결정적으로 생성
- Notebook JSON 유효성
- 실행 출력이 비어 있음
- 코드 셀 Python 문법
- 미해결 placeholder 없음
- 명백한 실수로 포함된 secret 없음
- 커밋된 README/노트북이 source와 일치

전체 전사 경로에는 Colab 전용 API, 모델 다운로드, GPU 가용성, 사용자가 제공한 미디어가 필요합니다. 따라서 GPU end-to-end 검증은 수동 UAT로 유지합니다. 일본어 경로는 Google Colab에서 실제 장시간 오디오로 검증했습니다.
