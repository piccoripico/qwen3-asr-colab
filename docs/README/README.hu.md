# Qwen3-ASR Colab

Google Colab notebookok audio- és videófájlok Qwen3-ASR-rel történő átírásához.

## Funkciók

- **Ingyenes:** Qwen3-ASR a Google Colab ingyenes GPU-jával.
- **Időbélyegek és feliratok:** a Qwen3-ForcedAligner által támogatott nyelvekhez igazított időbélyegek és SRT érhető el.
- **Nincs rögzített notebook-oldali fájlméretkorlát:** hosszú fájlok is feldolgozhatók.
- **Kötegelt feldolgozás:** több fájl egy futásban.
- **Google Drive:** közvetlen feltöltés vagy olvasás Google Drive-ról.
- **Teljesen online:** modellletöltés és átírás a Google Colabban.
- **Több formátum:** JSON, TXT, CSV, Markdown, Excel és SRT.
- **Kontextus:** a `CONTEXT_INFO` neveket, szervezeteket és szakkifejezéseket adhat meg.

## Repository felépítése

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

A template notebook a közös kódforrás. A locale fájlok nyelvspecifikus szöveget adnak a Colab felületéhez, például `# @title`, `# @markdown`, megjegyzések és kiválasztott üzenetek számára. Minden locale tartalmazza a gondozott japán notebook teljes placeholder-készletét.

A generált notebookok commitolva vannak, hogy a Colab linkek stabilak maradjanak.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Fordítások frissítése

A `translate_full_locales.py` karbantartási segédprogram, amely az angol locale alapján frissíti a többi locale-t, miközben megőrzi a kódtokeneket, modellazonosítókat és Colab beállításokat. Hivatalos kiadás előtt ellenőrizze a fordításokat.

## Ellenőrzések

```bash
python scripts/check_notebooks.py
```

A CI újragenerálja a README/notebook fájlokat és ellenőrzi a diffeket, notebook JSON-t, Python szintaxist, feloldatlan placeholdereket, mentett outputokat, nyilvánvaló secreteket és mind a 30 nyelvi artefact konzisztenciáját.

## Mit tud tesztelni a CI

A repository a notebookot terjeszthető artefactként tudja ellenőrizni:

- determinista generálás template-ből és locale fájlokból
- notebook JSON érvényesség
- üres execution outputok
- Python szintaxis a code cellekben
- nincs feloldatlan placeholder
- nincs nyilvánvaló véletlen secret
- a commitolt README/notebook fájlok egyeznek a forrásokkal

A teljes átírási út Colab-specifikus API-kat, modellletöltést, GPU-hozzáférést és felhasználói médiát igényel. A GPU end-to-end validáció kézi UAT marad. A japán útvonalat valós hosszú hanganyaggal validáltuk Google Colabban.
