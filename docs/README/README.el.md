# Qwen3-ASR Colab

Google Colab notebooks για μεταγραφή αρχείων ήχου και βίντεο με Qwen3-ASR.

## Δυνατότητες

- **Δωρεάν χρήση:** Qwen3-ASR με το δωρεάν GPU του Google Colab.
- **Χρονικές σημάνσεις και υπότιτλοι:** για γλώσσες που υποστηρίζονται από Qwen3-ForcedAligner παρέχονται ευθυγραμμισμένες χρονικές σημάνσεις και SRT.
- **Χωρίς σταθερό όριο μεγέθους αρχείου από το notebook:** μπορούν να επεξεργαστούν μεγάλα αρχεία.
- **Μαζική επεξεργασία:** πολλά αρχεία σε μία εκτέλεση.
- **Google Drive:** άμεση μεταφόρτωση ή ανάγνωση από Google Drive.
- **Πλήρως online:** λήψη μοντέλου και μεταγραφή στο Google Colab.
- **Πολλαπλές μορφές:** JSON, TXT, CSV, Markdown, Excel και SRT.
- **Συμφραζόμενα:** το `CONTEXT_INFO` μπορεί να παρέχει ονόματα, οργανισμούς και τεχνικούς όρους.

## Δομή αποθετηρίου

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Το template notebook είναι η κοινή πηγή κώδικα. Τα locale αρχεία παρέχουν κείμενο ανά γλώσσα για στοιχεία Colab όπως `# @title`, `# @markdown`, σχόλια και επιλεγμένα μηνύματα. Κάθε locale περιέχει το πλήρες σύνολο placeholder του επιμελημένου ιαπωνικού notebook.

Τα παραγόμενα notebooks γίνονται commit ώστε οι σύνδεσμοι Colab να παραμένουν σταθεροί.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Ανανέωση μεταφράσεων

Το `translate_full_locales.py` είναι εργαλείο συντήρησης που ανανεώνει άλλα locale από το αγγλικό, διατηρώντας code tokens, model identifiers και ρυθμίσεις Colab. Ελέγξτε τις μεταφράσεις πριν από επίσημη έκδοση.

## Έλεγχοι

```bash
python scripts/check_notebooks.py
```

Το CI αναδημιουργεί README/notebooks και ελέγχει διαφορές, notebook JSON, σύνταξη Python, ανεπίλυτα placeholders, αποθηκευμένα outputs, προφανή secrets και συνέπεια και των 30 γλωσσικών artefacts.

## Τι μπορεί να ελέγξει το CI

Το αποθετήριο μπορεί να ελέγξει το notebook ως διανεμητέο artefact:

- ντετερμινιστική δημιουργία από template και locale
- εγκυρότητα notebook JSON
- κενά execution outputs
- σύνταξη Python στα code cells
- χωρίς ανεπίλυτα placeholders
- χωρίς προφανή τυχαία secrets
- τα committed README/notebooks ταιριάζουν με τις πηγές

Η πλήρης διαδρομή μεταγραφής απαιτεί Colab-specific APIs, λήψεις μοντέλων, διαθεσιμότητα GPU και μέσα του χρήστη. Η GPU end-to-end επικύρωση παραμένει χειροκίνητο UAT. Η ιαπωνική διαδρομή έχει επικυρωθεί στο Google Colab με πραγματικό long-form audio.
