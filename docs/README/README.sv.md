# Qwen3-ASR Colab

Google Colab-notebooks för transkribering av ljud- och videofiler med Qwen3-ASR.

## Funktioner

- **Gratis:** använder [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) med Google Colabs kostnadsfria GPU.
- **Tidsstämplar och undertexter:** för språk som Qwen3-ForcedAligner stöder ger `Qwen3-ForcedAligner-0.6B` justerade tidsstämplar och SRT.
- **Ingen fast filstorleksgräns på notebooksidan:** långa filer kan bearbetas.
- **Batchbearbetning:** flera filer i en körning.
- **Google Drive:** direkt uppladdning eller läsning från Google Drive.
- **Helt online:** modellhämtning och transkribering på Google Colab.
- **Flera format:** JSON, TXT, CSV, Markdown, Excel och SRT.
- **Kontext:** `CONTEXT_INFO` kan ge namn, organisationer och tekniska termer.

## Repositorystruktur

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Template-notebooken är den gemensamma kodkällan. Locale-filer ger språkspecifik text för Colab, till exempel `# @title`, `# @markdown`, kommentarer och vissa användarmeddelanden. Varje locale innehåller hela placeholder-uppsättningen från den kuraterade japanska notebooken.

Genererade notebooks committas så att Colab-länkarna förblir stabila.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Uppdatera översättningar

`translate_full_locales.py` är ett underhållsverktyg som uppdaterar andra locales från engelska samtidigt som kodtokens, modell-ID:n och Colab-inställningar skyddas. Granska översättningarna före en formell release.

## Kontroller

```bash
python scripts/check_notebooks.py
```

CI bygger om README/notebooks och kontrollerar genereringsskillnader, Notebook JSON, Python-syntax, olösta placeholders, sparade cellutdata, uppenbara secrets och konsekvens för alla 30 språk.

## Vad CI kan testa

Det här repositoryt kan testa notebooken som distribuerbar artefakt:

- deterministisk generering från template och locale
- giltig Notebook JSON
- tomma exekveringsutdata
- Python-syntax i kodceller
- inga olösta placeholders
- inga uppenbara oavsiktliga secrets
- committade README/notebooks matchar sina källor

Hela transkriptionsflödet kräver Colab-specifika API:er, modellhämtningar, GPU-tillgänglighet och användarens media. GPU end-to-end-validering är därför fortsatt manuell UAT. Den japanska vägen har validerats i Google Colab med verkligt långt ljud.
