# Qwen3-ASR Colab

Notatniki Google Colab do transkrypcji plików audio i wideo za pomocą Qwen3-ASR.

## Funkcje

- **Bezpłatne użycie:** Qwen3-ASR z bezpłatnym GPU Google Colab.
- **Znaczniki czasu i napisy:** dla języków obsługiwanych przez Qwen3-ForcedAligner dostępne są wyrównane znaczniki czasu i SRT.
- **Brak stałego limitu rozmiaru pliku po stronie notatnika:** można przetwarzać długie pliki.
- **Przetwarzanie wsadowe:** wiele plików w jednym uruchomieniu.
- **Google Drive:** bezpośrednie przesyłanie lub odczyt z Google Drive.
- **W pełni online:** pobieranie modelu i transkrypcja odbywają się w Google Colab.
- **Wiele formatów:** JSON, TXT, CSV, Markdown, Excel i SRT.
- **Kontekst:** `CONTEXT_INFO` może zawierać nazwy, organizacje i terminy techniczne.

## Układ repozytorium

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Notatnik szablonowy jest wspólnym źródłem kodu. Pliki locale dostarczają tekst zależny od języka dla elementów Colab, takich jak `# @title`, `# @markdown`, komentarze i wybrane komunikaty. Każdy locale zawiera pełny zestaw placeholderów z kuratorowanego notatnika japońskiego.

Wygenerowane notatniki są commitowane, aby linki Colab pozostawały stabilne.

## Budowanie

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Aktualizacja tłumaczeń

`translate_full_locales.py` to narzędzie konserwacyjne aktualizujące inne locale z angielskiego, z zachowaniem tokenów kodu, identyfikatorów modeli i ustawień Colab. Przed wydaniem należy przejrzeć tłumaczenia.

## Kontrole

```bash
python scripts/check_notebooks.py
```

CI ponownie buduje README/notatniki i sprawdza różnice, JSON, składnię Python, nierozwiązane placeholdery, zapisane wyniki komórek, oczywiste sekrety oraz spójność wszystkich 30 artefaktów językowych.

## Co może testować CI

Repozytorium może testować notatnik jako artefakt dystrybucyjny:

- deterministyczne generowanie z szablonu i locale
- poprawność JSON notatnika
- puste wyniki wykonania
- składnia Python w komórkach kodu
- brak nierozwiązanych placeholderów
- brak oczywistych przypadkowych sekretów
- zgodność commitowanych README/notatników ze źródłami

Pełna transkrypcja wymaga API specyficznych dla Colab, pobierania modeli, dostępności GPU i mediów użytkownika. Walidacja GPU end-to-end pozostaje ręcznym UAT. Ścieżka japońska została zweryfikowana w Google Colab na rzeczywistym długim audio.
