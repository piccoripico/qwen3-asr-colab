# Qwen3-ASR Colab

Mga Google Colab notebook para mag-transcribe ng audio at video gamit ang Qwen3-ASR.

## Mga tampok

- **Libreng gamitin:** Qwen3-ASR kasama ang libreng GPU ng Google Colab.
- **Mga timestamp at subtitle:** para sa mga wikang suportado ng Qwen3-ForcedAligner, may aligned timestamps at SRT.
- **Walang nakapirming limitasyon sa laki ng file sa notebook:** maaaring iproseso ang mahahabang file.
- **Batch processing:** maraming file sa isang run.
- **Google Drive:** direktang upload o pagbasa mula Google Drive.
- **Ganap na online:** sa Google Colab ginagawa ang model download at transcription.
- **Maraming format:** JSON, TXT, CSV, Markdown, Excel at SRT.
- **Konteksto:** maaaring magbigay ang `CONTEXT_INFO` ng mga pangalan, organisasyon at teknikal na termino.

## Istruktura ng Repository

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Ang template notebook ang pinagsasaluhang source ng code. Ang locale files ang nagbibigay ng language-specific na text para sa Colab gaya ng `# @title`, `# @markdown`, comments at piling user messages. Bawat locale ay may kumpletong placeholder set mula sa curated Japanese notebook.

Naka-commit ang generated notebooks upang manatiling stable ang mga Colab link.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## I-refresh ang mga Translation

Ang `translate_full_locales.py` ay maintenance helper para i-refresh ang ibang locale mula sa English habang pinoprotektahan ang code tokens, model identifiers at Colab settings. Suriin ang translation bago ang formal release.

## Mga Check

```bash
python scripts/check_notebooks.py
```

Muling bina-build ng CI ang README/notebooks at sinusuri ang generated diffs, notebook JSON, Python syntax, unresolved placeholders, saved outputs, obvious secrets at consistency ng lahat ng 30 language artifacts.

## Ano ang Maaaring I-test ng CI

Maaaring i-test ng repository ang notebook bilang distributable artifact:

- deterministic generation mula template at locale files
- validity ng notebook JSON
- walang execution outputs
- Python syntax sa code cells
- walang unresolved placeholders
- walang obvious accidental secrets
- tugma sa source ang committed README/notebooks

Ang buong transcription path ay nangangailangan ng Colab-specific APIs, model downloads, GPU availability at media ng user. Kaya manual UAT pa rin ang GPU end-to-end validation. Na-validate ang Japanese path sa Google Colab gamit ang tunay na long-form audio.
