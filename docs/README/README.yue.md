# Qwen3-ASR Colab

喺 Google Colab 執行 Qwen3-ASR，將音訊同影片檔案轉寫成文字嘅 Notebook。

## 功能

- **免費使用：** 使用 [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) 同 Google Colab 免費 GPU runtime。
- **時間戳同字幕：** 對 Qwen3-ForcedAligner 支援嘅語言，`Qwen3-ForcedAligner-0.6B` 可以提供對齊時間戳同產生 SRT 字幕。
- **Notebook 端冇固定檔案大小限制：** 可以處理較長嘅音訊同影片。
- **批次處理：** 一次可以處理多個音訊同影片檔案。
- **支援 Google Drive：** 可以直接上載或者讀取 Google Drive 入面嘅檔案。
- **完全網上執行：** 模型下載同轉寫都喺 Google Colab 上進行。
- **多種輸出格式：** 支援 JSON、TXT、CSV、Markdown、Excel 同 SRT。
- **上下文提示：** `CONTEXT_INFO` 可以提供人名、機構名同專業術語。

## Repository 結構

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Template Notebook 係共用程式碼嘅來源。locale 檔案為 `# @title`、`# @markdown`、註解同部分用戶訊息等 Colab 介面文字提供各語言內容。每個 locale 都有同人工整理嘅日文 Notebook 相同嘅完整 placeholder 集合。

生成嘅 Notebook 會提交到 repository，保持 Colab 連結穩定。

## 生成

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## 更新翻譯

`translate_full_locales.py` 係維護用 script，可以由英文 locale 更新其他 locale，同時保護 code token、model identifier 同 Colab 設定。正式發佈前請檢查翻譯。

## 檢查

```bash
python scripts/check_notebooks.py
```

CI 會重新生成 README/Notebook，並檢查生成差異、Notebook JSON、Python 語法、未解決 placeholder、已儲存 cell output、明顯 secret，同埋 30 種語言產物嘅一致性。

## CI 可以檢查嘅內容

呢個 repository 可以將 Notebook 當成發佈產物檢查以下項目：

- 由 template 同 locale 決定性生成
- Notebook JSON 有效性
- execution output 為空
- code cell Python 語法
- 冇未解決 placeholder
- 明顯意外 secret
- 已提交 README/Notebook 同來源一致

完整轉寫流程需要 Colab 專用 API、model download、GPU 可用性同用戶提供嘅媒體檔案。因此 GPU end-to-end 驗證仍然係手動 UAT。日文路徑已經喺 Google Colab 用真實長音訊驗證。
