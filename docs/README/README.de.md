# Qwen3-ASR Colab

Google-Colab-Notebooks zum Transkribieren von Audio- und Videodateien mit Qwen3-ASR.

## Funktionen

- **Kostenlos nutzbar:** Verwendet [Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR) mit der kostenlosen GPU-Laufzeit von Google Colab.
- **Zeitstempel und Untertitel:** Für von Qwen3-ForcedAligner unterstützte Sprachen liefert `Qwen3-ForcedAligner-0.6B` ausgerichtete Zeitstempel und SRT-Untertitel.
- **Keine feste dateigrößenbezogene Notebook-Grenze:** Lange Audio- und Videodateien können verarbeitet werden.
- **Stapelverarbeitung:** Mehrere Dateien können in einem Durchlauf verarbeitet werden.
- **Google-Drive-Unterstützung:** Dateien können direkt hochgeladen oder aus Google Drive gelesen werden.
- **Vollständig online:** Modelldownload und Transkription laufen in Google Colab.
- **Mehrere Ausgabeformate:** JSON, TXT, CSV, Markdown, Excel und SRT werden unterstützt.
- **Kontexthinweise:** `CONTEXT_INFO` kann Namen, Organisationen und Fachbegriffe bereitstellen.

## Repository-Struktur

```text
notebook_template/
  Qwen3_ASR_Colab.template.ipynb
locales/
  *.json
notebooks/
  Qwen3_ASR_Colab_<language-code>.ipynb
docs/
  README/
    README.<language-code>.md
  ARCHITECTURE.md
scripts/
  languages.py
  build_readmes.py
  build_notebooks.py
  check_notebooks.py
  translate_full_locales.py
.github/
  workflows/
    ci.yml
```

Das Template-Notebook ist die gemeinsame Codequelle. Locale-Dateien liefern sprachspezifische Werte für Colab-Texte wie `# @title`, `# @markdown`, Kommentare und ausgewählte Benutzermeldungen. Jedes Locale enthält den vollständigen Placeholder-Satz des kuratierten japanischen Notebooks.

Generierte Notebooks werden committed, damit die Colab-Links stabil bleiben.

## Build

```bash
python scripts/build_readmes.py
python scripts/build_notebooks.py
```

## Übersetzungen aktualisieren

`translate_full_locales.py` ist ein Wartungswerkzeug, das andere Locales aus dem englischen Locale aktualisiert und dabei Code-Tokens, Modellkennungen und Colab-Einstellungen schützt. Übersetzungen vor einer formalen Veröffentlichung prüfen.

## Prüfungen

```bash
python scripts/check_notebooks.py
```

CI erzeugt README/Notebooks neu und prüft Generierungsdifferenzen, Notebook JSON, Python-Syntax, ungelöste Placeholder, gespeicherte Zellenausgaben, offensichtliche Geheimnisse und die Konsistenz aller 30 Sprach-Artefakte.

## Was CI prüfen kann

Dieses Repository kann das Notebook als verteilbares Artefakt auf Folgendes prüfen:

- deterministische Generierung aus Template und Locale-Dateien
- Gültigkeit des Notebook JSON
- leere Ausführungsausgaben
- Python-Syntax in Codezellen
- keine ungelösten Placeholder
- offensichtlich versehentlich enthaltene Geheimnisse
- committete README/Notebook-Dateien entsprechen ihren Quellen

Der vollständige Transkriptionspfad benötigt Colab-spezifische APIs, Modelldownloads, GPU-Verfügbarkeit und vom Benutzer bereitgestellte Medien. Die GPU-End-to-End-Validierung bleibt daher eine manuelle UAT. Der japanische Pfad wurde in Google Colab mit echtem Langform-Audio validiert.
